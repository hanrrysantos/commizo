# Commizo — instruções para o Claude Code

@AGENTS.md

O arquivo `AGENTS.md` é a fonte principal das decisões de produto, arquitetura, segurança, qualidade e identidade visual do Commizo. Antes de implementar, leia também o estado real do repositório e siga as instruções de escopo do usuário.

Não substitua Java/Spring Boot no backend nem altere o símbolo aprovado da marca (C formado por seis quadrados arredondados em tons de verde) sem autorização explícita.
